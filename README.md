# RepoFA.github.io

وب‌سایت رسمی و کاوشگر پروژه‌های اوپن‌سورس معرفی‌شده در کانال تلگرام **[RepoFA@](https://t.me/RepoFA)**.

## ویژگی‌ها
- آرشیو کامل و لحظه‌ای بیش از ۵۰۰ پست و پروژه
- دسته‌بندی موضوعی خودکار (هوش مصنوعی، وب، دو تولز، بک‌اند، لینوکس، امنیت و...)
- جستجوی آنی در عنوان، توضیحات، لینک‌ها و هشتگ‌ها
- پشتیبانی از تم تاریک و روشن
- فونت استاندارد و زیبای **وزیرمتن (Vazirmatn)**
- پایپ‌لاین خودکار همگام‌سازی با کانال تلگرام هر ۶ ساعت یک‌بار از طریق GitHub Actions

## توسعه محلی
```bash
# نصب پکیج‌ها
npm install

# اجرای لوکال
npm run dev

# همگام‌سازی دستی داده‌های تلگرام
python scripts/sync_telegram.py
```
